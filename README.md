## 🗞️ Overview

**The Gupta Gazette** combines the aesthetic discipline of fine typography, editorial broadsheets, and archival newsprint with interactive 2D physics mechanics. It showcases production-grade full-stack systems, campus startup infrastructure, and disciplined algorithmic computer science fundamentals.

### 🌟 Featured Highlights
- **Interactive Zero-G Sandbox:** Tactile 2D physics engine powered by **Matter.js** allowing visitors to decouple project dispatches, skill badges, and candidate tickets into floating, interactive bodies with mouse repulsion, inertia, and a clean grid reset.
- **Bespoke Editorial Cursor:** Ink pen drafting nib, loupe inspection reticles, and contextual hover badges (`VIEW ↗`, `ADMIT`, `FLING`).
- **Tactile Audio Synthesizer:** Pure Web Audio API mechanical sound effects (optional haptic feedback).
- **Flagship Production Systems:**
  1. **[Zappit](https://zappit.shop)** — Hyper-local campus food delivery platform with real-time Firebase Firestore snapshot listeners (<150ms sync).
  2. **Codexa** — Developer tooling and DSA milestone engine tracking 450+ curated algorithmic problems with spaced-repetition logic.
  3. **[RGPV Resources](https://rgpvpaper.in)** — Centralized academic exam repository serving **10,000+ engineering students**.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack) & React 19
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with custom typography & editorial palette
- **Physics Engine:** [Matter.js](https://brm.io/matter-js/)
- **Icons:** [Lucide React](https://lucide.dev/) & optimized inline SVGs
- **Fonts:** Playfair Display, Inter, Space Mono

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/dhruvgupta-og/dhruv-s-portfolio.git
cd dhruv-s-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm run start
```
